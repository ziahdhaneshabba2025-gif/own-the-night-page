# Noir Landing Page

Create a premium, modern, mobile-first landing page for a new fragrance under the existing Sarkar Perfume brand.

PRODUCT:
Brand: Sarkar Perfume
Fragrance Name: Sarkar Noir
Tagline: “Own the Night.”
Positioning: A bold, sophisticated and luxurious fragrance designed for evening wear and special occasions.

FRAGRANCE NOTES:

Top Notes: Bergamot, Saffron and Black Pepper

Heart Notes: Rose, Lavender and Leather

Base Notes: Oud, Amber, Vanilla and Musk

BRAND STORY:
“Sarkar Noir is created for those who walk into a room and leave an impression. Opening with fresh bergamot and spicy saffron, the fragrance develops into a rich heart of leather and rose before settling into a warm, sensual base of oud, amber, vanilla and musk.”

TARGET AUDIENCE:
Young adults who want a sophisticated, premium-looking fragrance with a bold and memorable personality.

PRICE:
Display the product price as ₹1,499 and include a prominent “Shop Now” CTA.

IMPORTANT BRAND RULE:
Do NOT redesign, modify, distort or alter the Sarkar Perfume packaging. If a product image is used, keep the packaging exactly as provided. The creativity should come from the website design, layout, typography, colours, animations and copywriting.

DESIGN:
Create a premium luxury fragrance aesthetic.
Use a sophisticated black, ivory/cream and subtle gold visual theme.
Keep the design elegant, minimal and high-end rather than overly decorative.
Use large typography and strong visual hierarchy.
Use generous whitespace.
Make the page feel like a premium perfume advertisement.

PAGE STRUCTURE:

HERO SECTION

Large product image area

“SARKAR PERFUME” brand name

“SARKAR NOIR” as the main heading

Tagline: “Own the Night.”

Short description

₹1,499 price

Primary CTA: “Shop Now”

Secondary CTA: “Discover the Scent”

PERFORMANCE REQUIREMENTS:
The website must be highly optimized for mobile devices.

Use responsive design throughout.

Optimize all images and avoid unnecessarily large image files.

Use modern image formats such as WebP where possible.

Lazy-load images that are below the fold.

Avoid unnecessary animations and heavy effects.

Minimize unnecessary JavaScript and dependencies.

Avoid large background videos.

Ensure buttons and text are easy to use/read on mobile.

Optimize for fast Largest Contentful Paint (LCP).

Avoid layout shifts.

Use semantic HTML and accessible buttons/links.

Ensure good contrast and accessibility.

Keep the page lightweight and clean.

RESPONSIVE DESIGN:
The page must look excellent on:

Mobile phones

Tablets

Desktop screens

On mobile, stack sections vertically, keep CTA buttons easy to tap, ensure the product image fits properly, and prevent horizontal scrolling.

ANIMATIONS:
Use subtle premium animations only:

Fade-in sections

Gentle image reveal

Small hover effects on desktop
Do not use heavy animations that could negatively affect PageSpeed performance.

SEO:
Add:

Page title: Sarkar Noir | Sarkar Perfume

Meta description: Discover Sarkar Noir by Sarkar Perfume — a bold and sophisticated fragrance with bergamot, saffron, oud, amber and vanilla. Own the night.

Proper H1/H2 heading hierarchy

Descriptive image alt text

Open Graph metadata

IMPORTANT:
Build the page as a polished, realistic commercial perfume landing page rather than a generic template. Make it feel premium, sophisticated, minimal and conversion-focused.

After creating the page, make sure it is fully responsive and optimized for PageSpeed Insights, especially Mobile.
